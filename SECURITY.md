# Security Policy

## Supported Versions

Only the latest published version of Jedison is supported. If you find a
vulnerability, please check whether it's still present on the latest release
before reporting.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private reporting:

1. Go to the [Security tab](https://github.com/germanbisurgi/jedison/security)
2. Click **"Report a vulnerability"**

This opens a private advisory visible only to the maintainer, so the issue
isn't disclosed before a fix is available.

You should get a response within a few days. If the report is confirmed,
a fix will be released as a patch version and the vulnerability disclosed
through a GitHub Security Advisory once users have had time to update.
